# Описание проекта

**Vexa** - настольное приложение для учёта личных финансов. Есть возможность вести счета в разных валютах, записывать доходы и расходы, переводить деньги между счетами и видеть общий баланс все счетов и всех счетов всех типов активов. 

Local-First: система работает без интернета, без регистраций, никакие данные не отправляются на удаленные сервера, все хранится только на вашем устройстве.

Проект абсолютно бесплатный, в будущем появится функция синхронизации между устройствами, это будет единственной платной функцией

## Возможности

- **Счета.** Наличные, дебетовые и кредитные карты. Для кредитных карт отображаются лимит, задолженность и доступная сумма.
- **Операции.** Доходы, расходы и переводы можно добавлять, редактировать и удалять. У каждой операции есть дата и необязательное описание до 50 символов.
- **Категории.** Отдельные категории для доходов и расходов.
- **Валюты.** Рубли, доллары США, евро и китайские юани. Общий баланс отображается в выбранной валюте. Для пересчёта используются захардкоженные курсы
- **История.** Операции отсортированы от новых к старым. Удаление счета или категории не удаляет связанную операцию, но ее можно удалить вручную
- **Обновление.** Приложение связано со страницей релизов этого репозитория, при появлении нового UI отрисовывает соответствующее сообщение и дает ссылку на скачивание.
