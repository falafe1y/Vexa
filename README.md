# Суть проекта
*Vexa* - система учета финансов. MVP должен иметь базовый функционал: расход, доход, перевод между счетами, учет в разной валюте (захардкоженной), добавление\удаление операций, счетов и категорий операций, а так же привязку к релизам репозитория проекта на гитхабе в качестве простой системы обновлений.

core - ядро, базовые вычисления, бизнес-логика
services - промежуточный слой между core и UI
UI - графическое представление управления: кнопки, поля ввода и тд. В будущем может так же поддерживать и терминал

### Архитектура 
Слоеная DDD, делится на core (в т.ч. DB), services, UI
core/model:
- money - представление денежной единицы в минимальных единицах (для рубля - в копейках)
- account - сущность счета
- category - сущность категорий
- currency - сущность валюты как объекта, не ее курс
- exchange rate - модель пересчета суммы из одной валюты в другую
- operation - сущность операции: расход, доход и перевод
- ledger - единый журнал, в котором хранятся в связанном виде данные о счетах, операциях и категориях

core/db:
- database - простой класс, напрямую работающий с sqlite базой. Выполняется в отдельном потоке

services:
- LedgerService - связывает БД и журнал из ядра
