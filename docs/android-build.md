# Сборка Android из Windows

В Qt Maintenance Tool должен быть установлен комплект Qt той же версии,
которую использует проект: например, Qt 6.11.1 → Android → arm64-v8a.
В Qt Creator выберите соответствующий комплект и настройте Android SDK,
NDK и JDK. Предупреждение о недостающем компоненте Qt исправляется через
Maintenance Tool, а не заменой пути к OpenSSL.

Для Android нужны библиотеки OpenSSL, собранные под выбранную архитектуру.
OpenSSL из `C:/msys64/mingw64` предназначен для Windows.

При первой настройке Android проект автоматически загружает пакет
`KDAB/android_openssl`, на который ссылается документация Qt. Используется
фиксированная версия пакета: `b71f1470962019bd89534a2919f5925f93bc5779`.
Загрузка требует доступа к GitHub. Библиотеки подключаются к SQLCipher,
а `libcrypto_3.so` и `libssl_3.so` включаются в APK. Шрифты интерфейса также
включаются в мобильную сборку.

Если пакет уже скачан через Qt Creator или отдельно, укажите в параметрах
CMake путь к его корневому каталогу:

```text
VEXA_ANDROID_OPENSSL_ROOT:PATH=D:/Qt/android_openssl
```

В этом каталоге должен находиться `android_openssl.cmake`. Не указывайте
вместо него каталог `ssl_3/arm64-v8a` или установку OpenSSL для Windows.
Локальный путь отключает автоматическую загрузку. Допускаются пробелы в пути.

После изменения параметров выполните «Сборка → Очистить конфигурацию CMake»
и запустите настройку заново. Обновите обе конфигурации: Debug и Release.
Если пункта очистки нет, закройте проект и удалите только его два каталога
сборки `build/Qt_6_11_1_for_Android_arm64_v8a_Debug` и
`build/Qt_6_11_1_for_Android_arm64_v8a_Release`, затем откройте проект заново.

Справка Qt: <https://doc.qt.io/qt-6/android-openssl-support.html>.
